# TXAuction source + unified Auctions tab + readable close times (2026-10-10)

## Goal
1. Add txauction.com (Gaston & Sheehan; example lot https://www.txauction.com/auctions/31431/lot/57702-lot-11) as a daily-scraped deals source that finds every chair lot (banquet, stackable/stacking, any chair) and shows them in the admin Auctions tab like GovDeals.
2. Remove the per-source selector in the Auctions tab; show one combined list with a source badge on each card.
3. Human-readable close time on cards: "3d 4h left · Tue Oct 14", "5h 0m left · today 5:00 PM", "Ended Oct 9".

## Recon (live 2026-10-10)
- React SSR site; every page embeds `window.__APOLLO_STATE__ = {...}` in a `<script>` — regex `window\.__APOLLO_STATE__\s*=\s*(\{.*?\});?\s*</script>` (re.S) → json. Plain requests with desktop UA → 200.
- robots.txt disallows /admin/, /api/, /asset/ → NEVER call /api; parse SSR HTML only; pace ≥ 2 s/request.
- Search live lots: `/search?search=<term>&page=<n>` → ROOT_QUERY key starting `lots(` → `{total, lots:[{__ref:"AuctionLot.<id>"}]}`, pageSize 25. Param must be `search`.
- Live auctions index: `/auctions` (`?page=2`) → `Auction.<id>` entities: auction_id, title, auction_status (200 live / 100 upcoming / 400 closed), start_time, end_time, auction_location{line_1, city, state_name ("Texas"), zip_code}. Lot location comes from here (search cards have lot_location null).
- Catalog: `/auctions/<auction_id>?page=<n>&search=<term>` (pageSize 50).
- Lot page: `/auctions/<auction_id>/lot/<auction_lot_id>` → AuctionLot.<id> plus images[] (cached_assets[] variants large/medium/small/thumb), front_lot_location, basic_consignor, winning_bidder.user_display.
- AuctionLot fields: auction_lot_id, auction_id, lot_number, title (just "Lot 11" — real text is description / description_plain), start_time / end_time / original_end_time (ISO UTC with Z; end_time moves on soft close), auction_lot_status (100 live, 200 ended), is_past_end_time, winning_bid_amount (null at 0 bids), bid_count, starting_bid, required_bid, quantity (always 1), has_reserve / reserve_met, is_no_sale, primary_image{url,large,medium,small,thumb}, image_count, category{category_id,name}, dynamic_fields[label=Seller].data.value, basic_consignor{company,first_name,last_name}.
- Example: lot 57702 "(500) MTS Seating Omega Stacker event chairs…", ended 2026-08-14T16:58Z, 682 bids, $5645; sibling 57700 "(50) …" $350. Quantity convention "(N) …" prefix.

## Architecture
1. **Adapter** `deals/adapters/txauction.py` (SiteAdapter contract, modelled on publicsurplus.py), ordinal 10, enabled=True, rows into deal_lots/deal_snapshots with site='txauction'. native_id = f"{auction_id}/{auction_lot_id}", ids via synth_ids(SITE, native_id, ordinal=10). Pure fixture-tested functions: extract_apollo_state (ValueError when absent), parse_search_page → (total, cards), parse_auction_index → {auction_id: {title,city,state,zip,status,end_time}}, parse_lot_page (gallery = large, fallback medium), derive_title(description_plain, lot_number) first sentence ≤140 chars never empty, parse_price (winning_bid if bid_count>0 else starting_bid; missing → ValueError, never 0), _end_utc (missing → ValueError), _status ("STA" if status 100 and not past end else "CLO"), card_to_lot (state name → 2-letter, raw trimmed ≤2 KB, canonical_category "other"). Adapter: SEARCH_TERMS ["chair","chairs","banquet","stackable","stacking","seating"], paged search, dedupe by auction_lot_id, ValueError rows logged+skipped, 403/429 → stop not bypass, locations loaded once from /auctions, refetch(keys) via lot pages, fetch_gallery.
2. **Bridge** — the Auctions tab reads `auction_listings` (automation/auctions_supabase.py), not deal_lots. `deals/listings_bridge.py` mirrors active profile-matching txauction deal_lots rows into auction_listings: asset_id 'tx:<auction_lot_id>', link = lot URL, price "$1,234.00", location "City, ST, United States", end_date ISO-Z, image_url hero, quantity seeded from explicit_title_quantity → 'regex_title' else 'llm_missing', then verified via auction_extractors/quantity_llm.refine_quantities_with_llm exactly as scripts/backfill_quantities_llm.py calls it (batches of 12; failure → quantity None, 'llm_failed'). Upsert ON CONFLICT(asset_id) keeping first_seen_at and never stomping quantity cols when existing quantity_source IN ('llm','structured'). mirror(site, profile, dry_run).
3. **Schedule** — append to scripts/run_discovery.sh (black-whole-discovery Render cron, 08:00 UTC), non-fatal: `discover --site txauction --profile chairs`, `watch-once --site txauction`, `mirror-auctions --site txauction --profile chairs`, each `|| echo ... FAILED — continuing`. No Render config change.
4. **Store/watch/CLI** — store.due_for_poll gets a site filter (default 'govdeals') so the GovDeals watch cron never feeds tx rows to mapping.asset_to_lot / maestro; for non-govdeals build Lot from stored columns (store.row_to_lot). watch.poll_once(site=...). cli: foreign --site sweeps once (not once per category id); --site on watch-once; new mirror-auctions subcommand. sites.py: register txauction (ordinal 10, lot_url builder).
5. **No migration** (site columns are unconstrained TEXT). Next free number would be 027 — don't consume it.
6. **Read side** — auctions_supabase._SOURCE_FRAG["tx"]="txauction.com"; Source adds "all","tx"; source_of_link(link); "all" omits the link ILIKE clause; get_top_lots items gain source, source_name, end_utc (ISO-Z via automation.favorites._parse_end_date, naive = US/Eastern); cache_stats adds tx. app.py: /api/auctions source default "all", allowed {all,gd,ps,bs,tx}, else 400; /api/listings uses source_of_link; _asset_id_from_link handles txauction.com/auctions/\d+/lot/(\d+) → tx:<id>; same in auction_extractors/listings_db.py extract_asset_id. shared.js SOURCE_NAMES.tx='TXAuction' + export sourceOfLink; listings_db.js SOURCES add tx. Favorites/tracking skip tx: keys like ps:/bs:.
7. **Unified Auctions view** — remove the #auc-source seg (template + auctions.js SOURCES/auc.source/URL param; old ?source= ignored). Keep profile, search, min units, top N, condition, show ended, stale days, reload, scrape-now dropdown, queue all, map. Use auc.stats totals instead of by_source[auc.source]. Card gets `<span class="badge badge-src src-${src}">` first in .auction-meta (also favorite cards). Cache header keeps per-source counts. Hero copy mentions all four sources. CSS tokens only (.src-gd accent, .src-ps success, .src-bs warn, .src-tx info/muted).
8. **Readable time** — pure ESM automation/web/static/admin/fmt_time.js exporting fmtClose(iso, nowMs=Date.now()) → {label, cls, title}: invalid → empty (card falls back to it.time_left); ended → "Ended Oct 9" (+", YYYY" if other year), cls ends-over; <1h → "30m left · today 3:00 PM" ends-red; <24h → "5h 0m left · today|tomorrow 5:00 PM" (ends-red if <2h else ends-yellow); else "3d 4h left · Tue Oct 13" (+year if differs). title = full toLocaleString. Viewer-local tz. Used on auction cards (and favorites remaining); 60 s re-render tick while pane visible (no fetch).
9. **Quantity** — auction_extractors/quantity_infer.py supports a leading "(N) … chairs" pattern ("(500) MTS Seating Omega Stacker event chairs" → 500; "(5173) ACCESSIBLE VAN" → None).
10. **Docs** — CLAUDE.md deals block one line; docs/claude-reference/deals.md TXAuction section; deals/adapters/ONBOARDING.md note on the Apollo-state pattern.
