HOW IT WORKS

One lot moves through four stages. Each stage is labelled with what is built and what is still in progress.

  1. 1

    Scan the auctions

    A scanner sweeps every open GovDeals auction on a schedule. It reads the quantity out of each title so a lot is priced per unit, adds the buyer's premium, and keeps the final result when the auction closes.

    Built Covers GovDeals. More auction sites are being added.

  2. 2

    Keep one ledger

    Every lot you win becomes one row: how many are left, the price, the status, the photos. Sell some and the row changes once. Everything else reads from it.

    Built It is the ledger behind this store.

  3. 3

    List on every channel

    The ledger feeds a storefront, a Facebook catalog and Google Merchant Center. Marketplace posts wait in a queue until you approve them, and a lot that sells out drops off the feeds on its own.

    Partly built The storefront and both feeds are built. eBay and Craigslist posting are in progress.

  4. 4

    Work the buyers

    Buyer conversations land in one list with a stage and a next action. Replies are drafted for you, and nothing sends until you approve it. Prices, addresses and pickup times are always your call.

    Partly built Facebook Marketplace is built. Other channels are in progress.

Built and run by Abdel Nasser. Python and FastAPI on Postgres, Playwright for the browser work, Cloudflare R2 for photos, plain ES modules on the front end. The deal finder above reads the same public API as the full deal feed.
