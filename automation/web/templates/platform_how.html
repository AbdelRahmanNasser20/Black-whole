The pipeline

Five steps, every half hour, for {{ platform_sources | join(", ") }}.

  1. Record

    One recorder per site reads the public listing pages or the site's own JSON. A site that blocks a region is read through a proxy; a site that changes shape trips a breaker and stops, so a broken read is never mistaken for an empty day.

  2. Normalise

    Every lot becomes one row: title, category, current bid, bid count, close time in UTC, city and state, the source link. A lot that states a quantity gets a price per unit.

  3. Judge

    A language model sorts each lot into a category. Comparable confirmed sales set the Flip Score and a recommended max bid. No comparable sale, no number — the lot says so.

  4. Publish

    The public feed passes one policy: the operator's own picks and tracked lots stay out, photos stay on the source site, and the anonymous feed has a depth cap and a rate limit.

  5. Alert

    A saved search runs on a schedule and sends only the lots that are new since the last look. Saved searches work with no account; alerts need a sign-in.

What the AI does today

  • Sorts lots into categories, with a confidence that gates the sort.
  • Counts the units in a lot from its title and photos; a low-confidence count is shown as unverified and never overrides the title.
  • Judges a lot against confirmed sales of comparable lots.

What it does not do yet

  • Plain-English search over the feed.
  • Sold prices for every source: confirmed closes come from the sites that publish them.
  • A price for a lot with no comparable sale. It stays blank.

The stack

  • Python · FastAPI
  • PostgreSQL (Supabase)
  • Playwright recorders
  • Render web + crons
  • Cloudflare CDN · R2
  • MapLibre GL
  • pytest

Rules it keeps

  • Not affiliated with any auction site or agency. Every lot links to its source.
  • Photos are never copied or stored; the page shows the source's own image.
  • No operator pick, no stored address, no buyer's data ever reaches the public feed.
  • Every public read is rate-limited and cached at the edge, so one visitor cannot pull the whole feed.
